## 快速开始工作流

### 第 1 步：划分数据集

在训练之前，先将原始数据集拆分为互不重叠的训练集和测试集：

```bash
# 按运动员划分（将 Skater_D 单独划入测试集，其余在训练集）
python split_dataset.py --mode skater --test_skaters Skater_D

# 随机 8:2 划分
python split_dataset.py --mode random --ratio 0.8 --seed 42

# 强制覆盖已有输出目录
python split_dataset.py --mode skater --test_skaters Skater_D --force
```

划分结果输出至 `data/npy_train/` 和 `data/npy_test/`（路径在 `config.py` 中配置）。

---

### 第 2 步：训练八叉树模型

```bash
# 默认训练（使用 config 中的 TRAIN_DATA_DIR）
python train.py

# 指定输出文件路径或并行进程数
python train.py --output-tree "models/model.npz" --output-metadata "models/model.pkl" --workers 8

# 指定数据目录（覆盖 config）
python train.py --data-dir "data/npy_train"
```

模型保存至 `models/model.npz` 和 `models/model.pkl`。

---

### 第 3 步：评估模型泛化能力

```bash
python evaluate.py
```

评估脚本将会：
1. 加载 `models/model.npz` 中训练好的八叉树
2. 遍历 `data/npy_test/` 中每一帧测试数据，执行下探匹配
3. 若匹配成功（自然命中）则计入命中率；若遇到未知象限，则启用欧氏距离最近邻兜底并记录

输出报告包含：

| 指标 | 含义 |
|------|------|
| **初始模型识别命中率** | 无任何算法干预的纯自然命中比例 |
| **兜底干预帧数** | 因路径中断而被最近邻算法接管的帧数 |
| **平均中断深度** | 中断发生时位于八叉树第几层（越浅差异越大）|
| **各类别初始命中率** | 按跳跃类型（Axel/Flip/Loop 等）细分的命中统计 |

兜底日志保存至 `output/fallback_records.json`，可用可视化工具进一步审查。

---

### 第 4 步：执行相似帧查询

```bash
# 相似帧检索（Top-K）
python query.py --npy-file "data/npy/Skater_A/Axel/Axel_1.npy" --frame-index 100 --model-tree models/model.npz

# 同节点查询（查询与目标帧落在同一八叉树叶节点的所有帧）
python query.py --npy-file "data/npy/Skater_A/Axel/Axel_1.npy" --frame-index 0 --same-node
```

**关键参数说明：**
- `--npy-file`：待查询的 NPY 文件路径
- `--frame-index`：查询该文件中的第几帧（从 0 开始）
- `--top-k`：返回最相似的前 K 个结果（默认 5）
- `--model-tree`：指定模型文件（默认 `models/model.npz`）
- `--same-node`：切换为同节点查询模式

## 可视化工具

| 脚本 | 启动端口 | 说明 |
|------|----------|------|
| `python scripts/visualize_leaf_nodes_web.py` | 8051 | 叶节点动作探索器：浏览八叉树叶节点中的骨架姿态，支持翻页和动作标注 |
| `python scripts/visualize_fallback_web.py` | 8052 | 兜底可视化审查：左右画布对比中断帧与兜底叶节点的骨架相似度，右侧可手动切换帧 |
| `python scripts/verify_overlap.py` | — | 骨骼归一化验证：生成 `output/overlap_verification.html` |
| `python utils/action_space_explorer.py` | 动态 | 动作空间 3D 星系图：t-SNE 降维 + K-Means 聚类分析 |

## 配置说明（config.py）

| 配置项 | 说明 |
|--------|------|
| `FS_JUMP3D_DATA_DIR` | 原始 NPY 数据根目录 |
| `TRAIN_DATA_DIR` | 训练集目录（split_dataset.py 输出目标） |
| `TEST_DATA_DIR` | 测试集目录（split_dataset.py 输出目标） |
| `JOINT_PAIRS` | 参与八叉树切分的关节组（决定树的结构维度） |
| `PAIR_ITERATION_DEPTH` | 每组关节使用的对应层数 |
| `MAX_DEPTH` | 八叉树最大深度（自动由 JOINT_PAIRS 和 PAIR_ITERATION_DEPTH 计算） |
| `STANDARD_BONE_RATIOS` | 标准骨骼比例（由 `calculate_standard_skeleton.py` 计算） |
| `NORMALIZE_REFERENCE_LENGTH` | 归一化参考基准长度 |
