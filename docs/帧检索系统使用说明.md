# 八叉树帧检索系统 - 使用说明

## 项目结构

```
八叉树/
├── config.py              # 全局配置（数据路径、关节定义、归一化参数等）

├── flat_octree.py         # 扁平化八叉树数据结构
├── octree_builder.py      # 八叉树构建逻辑
├── data_structures.py     # FrameMetadata 数据结构定义
├── npy_loader.py          # NPY 格式数据加载、骨架归一化
├── data_loader.py         # BVH 格式数据加载（旧格式支持）
├── data_frame.py          # BVH 帧解析与缓存（旧格式支持）
├── similarity.py          # 帧相似度计算
├── rotation_utils.py      # 旋转增强工具
├── requirements.txt       # Python 依赖列表
│
├── data/                  # 数据目录
│   ├── npy/               # NPY 动作捕捉数据（按运动员/动作分组）
│   ├── json/              # JSON 原始数据（可转换为 npy）
│   └── leaf_labels.json   # 叶节点动作标注文件
│
├── models/                # 训练好的模型文件
│   ├── model.npz          # 默认八叉树索引
│   ├── model.pkl          # 默认帧元数据
│   └── ...                # 其他模型变体
│
├── scripts/               # 独立运行脚本
│   ├── visualize_leaf_nodes_web.py   # 叶节点动作标注与可视化（Dash Web App）
│   ├── verify_overlap.py             # 骨骼归一化验证（生成 HTML 对比图）
│   └── analyze_stats.py              # 骨骼长度统计分析
│
├── utils/                 # 工具模块
│   ├── visualize_npy.py              # NPY 数据可视化工具
│   ├── action_space_explorer.py      # 动作空间探索（t-SNE + K-Means，Dash）
│   ├── calculate_standard_skeleton.py # 计算标准骨骼比例并更新 config
│   ├── format.py                     # JSON 转 NPY 格式转换工具
│   ├── rig.json                      # 关节映射配置文件
│   └── visualization.ipynb           # Jupyter 可视化笔记本
│
├── output/                # 输出文件目录
│   ├── action_space_cache.csv         # t-SNE 降维缓存
│   ├── overlap_verification.html      # 骨骼归一化验证结果
│   └── 结果导出/                      # K-Means 聚类导出的 CSV 文件
│
└── docs/                  # 文档目录
    ├── 帧检索系统使用说明.md（本文件）
    └── FLAT_OCTREE_README.txt
```

## 可视化工具（直接运行）

| 脚本 | 说明 |
|------|------|
| `scripts/visualize_leaf_nodes_web.py` | 叶节点动作探索器：浏览八叉树叶节点中的骨架姿态，并为其标注动作名称 |
| `scripts/verify_overlap.py` | 骨骼归一化验证：对比原始、重定向、对齐后的骨骼，输出 `output/overlap_verification.html` |
| `utils/action_space_explorer.py` | 动作空间 3D 星系图：t-SNE 降维 + K-Means 聚类分析 |
| `utils/visualize_npy.py` | 可视化单帧或某个 NPY 文件 |

## 配置说明（config.py）

- **数据集路径**：`FS_JUMP3D_DATA_DIR` — NPY 数据根目录
- **骨骼朝向对齐**：在 `npy_loader.py` 中，`normalize: bool = False` 控制是否启用
- **标准骨骼比例**：`STANDARD_BONE_RATIOS` — 由 `utils/calculate_standard_skeleton.py` 自动计算并写入

## 训练模型

```bash
# 默认训练（使用 config 中配置的路径）
python train.py

# 指定输出文件名或并行进程数
python train.py --output-tree "models/model.npz" --output-metadata "models/model.pkl" --workers 8

# 仅训练某个子目录
python train.py --data-dir "data/npy/Skater_A/Axel"
```

---

## 执行查询

```bash
# 相似帧检索（Top-K）
python query.py --npy-file "data/npy/Skater_A/Axel/Axel_1.npy" --frame-index 100 --model-tree models/model.npz

# 同节点查询（查询与目标帧落在同一八叉树叶节点的所有帧）
python query.py --npy-file "data/npy/Skater_A/Axel/Axel_1.npy" --frame-index 0 --same-node
```

**关键参数说明：**
- `--npy-file`：待查询的 NPY 文件路径
- `--frame-index`：查询该文件中的第几帧（从 0 开始）
- `--top-k`：返回最相似的前 K 个结果（默认 5）
- `--model-tree`：指定训练好的模型文件（默认 `models/model.npz`）
- `--same-node`：切换为同节点查询模式
